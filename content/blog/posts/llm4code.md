<h3 id="humaneval">HumanEval</h3>
<p>This is an evaluation harness for the HumanEval problem solving dataset described in the paper <a href="https://arxiv.org/pdf/2107.03374.pdf" target="_blank" rel="noopener">&ldquo;Evaluating Large Language Models Trained on Code&rdquo;</a>. It used to measure functional correctness for synthesizing programs from docstrings. It consists of 164 original programming problems, assessing language comprehension, algorithms, and simple mathematics, with some comparable to simple software interview questions. At the same time, you can find the latest models and advancements in <a href="https://paperswithcode.com/sota/code-generation-on-humaneval" target="_blank" rel="noopener">PapersWithCode</a>.

<h3 id="codellama">CodeLlama</h3>
<p>Maybe you haven&rsquo;t excperienced CodeLlama yet, the Huggingface official group has deployed a <a href="https://huggingface.co/chat" target="_blank" rel="noopener">playground</a> for everyone where you can Preliminarily evaluate it in your target task.</p>
<p>After you have seen its performance on your task and gain much confidence in CodeLlama, you might want to give it a shot where you can delve deeper into the paper, even deploy and finetune it. The model weights are available in <a href="https://huggingface.co/codellama" target="_blank" rel="noopener">Huggingface</a>. If you go through the <a href="https://arxiv.org/pdf/2308.12950v2.pdf" target="_blank" rel="noopener">paper</a>, you might find a really distinct model named &ldquo;<strong>unnatural CodeLlama</strong>&rdquo; whose performance is nearly the same as GPT-4 under the code scenario.</p>
<h5 id="what-is-unnatural-instruction">What is unnatural instruction</h5>
<p>In December 2022, Meta AI with Tel Aviv University published the paper named <a href="https://arxiv.org/pdf/2212.09689.pdf" target="_blank" rel="noopener">Unnatural Instructions: Tuning Language Models with (Almost) No Human Labor</a>. The paper talks about how Meta created a large dataset of creative and diverse instructions and collected 64,000 examples by prompting a language model. This was then further prompted to create a total of 240,000 examples on inputs and outputs, which contained only a little amount of noise. Unnatural Instructions is a dataset of instructions automatically generated by a Large Language model.</p>

<h3 id="codegeex2">CodeGeeX2</h3>
<p>CodeGeeX2 是多语言代码生成模型 CodeGeeX (KDD’23) 的第二代模型。不同于一代 CodeGeeX（完全在国产华为昇腾芯片平台训练） ，CodeGeeX2 是基于 ChatGLM2 架构加入代码预训练实现，得益于 ChatGLM2 的更优性能，CodeGeeX2 在多项指标上取得性能提升（+107% &gt; CodeGeeX；仅60亿参数即超过150亿参数的 StarCoder-15B 近10%）</p>
<h3 id="wizardcode">WizardCode</h3>
<p>Code Large Language Models (Code LLMs), such as StarCoder, have demonstrated exceptional performance in code-related tasks. However, most existing models are solely pre-trained on extensive raw code data without instruction fine-tuning. In this paper, we introduce WizardCoder, which empowers Code LLMs with complex instruction fine-tuning, by adapting the Evol-Instruct method to the domain of code. Through comprehensive experiments on four prominent code generation benchmarks, namely HumanEval, HumanEval+, MBPP, and DS-1000, we unveil the exceptional capabilities of our model. It surpasses all other open-source Code LLMs by a substantial margin. Moreover, our model even outperforms the largest closed LLMs, Anthropic&rsquo;s Claude and Google&rsquo;s Bard, on HumanEval and HumanEval+.</p>
<h3 id="phi-1">phi-1</h3>
<p>phi-1 is proposed by teams of Microsoft in the <a href="https://arxiv.org/pdf/2306.11644v2.pdf" target="_blank" rel="noopener">&quot;<em>Textbooks Are All You Need</em>&quot;</a>. phi-1 is a Transformer-based model with 1.3B parameters, trained for 4 days on 8 A100s, using a selection of &ldquo;textbook quality&rdquo; data from the web (6B tokens) and synthetically generated textbooks and exercises with GPT-3.5 (1B tokens). Despite this small scale, phi-1 attains pass@1 accuracy 50.6% on HumanEval and 55.5% on MBPP. It also displays surprising emergent properties compared to phi-1-base, our model before our finetuning stage on a dataset of coding exercises, and phi-1-small, a smaller model with 350M parameters trained with the same pipeline as phi-1 that still achieves 45% on HumanEval.
</p>
<h3 id="phind">Phind</h3>
<p><a href="https://www.phind.com/" target="_blank" rel="noopener">Phind</a> is an intelligent search engine and assistant for programmers. With Phind, you&rsquo;ll get the answer you&rsquo;re looking for in seconds instead of hours. It will guide you step-by-step from that idea in your head to a working app. Phind is smart enough to proactively ask you questions to clarify its assumptions and to browse the web (or your codebase) when it needs additional context. With their new VS Code extension, you can now get Phind&rsquo;s help right in your editor.</p>
<p>August 28th Update: They&rsquo;ve trained a new model, Phind-CodeLlama-34B-v2, that achieves 73.8% pass@1 on HumanEval. See the <a href="https://www.phind.com/blog/code-llama-beats-gpt4" target="_blank" rel="noopener">blog</a>.</p>
<p>They have released all models on <a href="https://huggingface.co/Phind" target="_blank" rel="noopener">Huggingface</a> to bolster the open-source community.</p>
<h3 id="vscode-plugin-with-llms">Vscode Plugin with LLMs</h3>
<p>We have mentioned above that most of the models are incorporated into the plugin for the convenience in coding procedure. In order to find out the mechanism, we take CodeGeex as an example. First we install the CodeGeex plugin and log in, then we can use <code>developer tool (ctl+shift+I)</code> to ananlyze the network and console output.
We further go to the directory <code>'~/.vscode/aminer.codegeex-2.1.3'</code> where exists the source code of the plugin and find the post method in line42-64 of <code>'~/.vscode/extensions/aminer.codegeex-2.1.3/out/utils/getCodeCompletions.js'</code>. Besides, with seamless effort we can obtain the api url: <code>'https://tianqi.aminer.cn/api/v2/multilingual_code_generate_adapt'</code>, which you can try with any frontend tools. So far we can get preliminary thought about the mechanism: Frontend + Api calling, so the keys of user experience are still the <code>'clever'</code> model and network.</p>
